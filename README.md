# 🌟 Instalação e uso 🌟

Siga as instruções a seguir para ver o projeto rodando :)

1. Clique no botão Code e copie a URL do projeto:

```bash
https://github.com/LucasBoaratti/Starfolio.git
```

2. Abra o Prompt de comando (ou PowerShell ou GitBash) em sua área de trabalho ou em documentos e realize o seguinte comando:

OBS: Certifique que o Git está instalado no seu computador. Caso não esteja, instale aqui: [Git](https://git-scm.com/downloads)

```bash 
git clone https://github.com/LucasBoaratti/Starfolio.git
```

3. Acesse a pasta do projeto:

```bash
cd .\Starfolio
```

4. Agora, entre no VSCode:

```bash
code .
```

5. Verifique se o node está instalado em seu PC;

6. Se não tiver, faça o download [aqui](https://nodejs.org/en/download);

7. Agora, verifique se o Angular está instalado globalmente em seu PC;

8. Se não tiver, faça o seguinte comando:

```bash
npm i -g @angular/cli
```

9. Agora, abra o terminal com CTRL + J ou CTRL + ' e instale a pasta node_modules:

```bash
npm install
```

10. Rode o servidor:

```bash
ng serve
```

11. Agora, acesse a URL que foi gerada:

```bash
http://localhost:4200/
```

E pronto! Agora você pode acessar meu portfólio :D
